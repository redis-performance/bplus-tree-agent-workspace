# Adversarial review prompt

Review the exact proposed commit and all population/measurement evidence. Record five
lenses: semantics/ownership; portability/UB; regression-test strength; measurement and
selection validity; maintainability. Inspect packed scores, binary member lengths,
leaf-ID lifetime, mutation positions, scan resize progress and iterator invalidation.
Check baseline/referee identity, A/A precision, serial ABBA, guard cases, memory accounting,
profiles and fresh confirmation. Verdict: READY or NEEDS-WORK, with evidence per lens.
READY allows workspace acceptance only; it is not authorisation for upstream actions.
