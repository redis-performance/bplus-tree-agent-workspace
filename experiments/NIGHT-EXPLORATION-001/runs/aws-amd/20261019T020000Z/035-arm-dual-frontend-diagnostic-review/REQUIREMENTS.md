## What the profiles must prove, and what they cannot

1. Scope controls prove that construction, H4 verification and either warmup did not dominate the measured region. Validate literal completed traversal work and known outside-work exclusion; zero losses alone does not prove perfect scope.
2. Exact per-frontend/per-source mapping proves that sampled tree instructions correspond to each actual timing binary. Review full decoder/IteratorNext bodies and callsites, not only the one mask sequence. Keep missing/different bytes and unknowns in denominators.
3. Because prior024 leaves nearly half the sampled period in differently mapped caller code, require a **source-linked caller/basic-block map** for both frontends. Track numeric conversion versus bit consumption, dependency chains, branches, spills and call/return boundaries where actually present. Do not silently normalize different instructions or treat an ancestor frame as exclusive cost. If caller mapping cannot be established, report the causal question unresolved.
4. Reconstruct paired instructions/cycles/branches/misses per actual visit and exclusive sample periods for both frontends, with every seed reported. A frontend×candidate interaction can localize a discrepancy but cannot isolate which of scores, warmup, checksum, allocation/layout or caller code causes it. The new diagnostic should report actual signs; it must not require a favorable instruction reduction or discard a counter-direction mismatch. A mismatch is useful evidence against the prior mechanism, not grounds to retune.
5. Only profile-supported, source-linked evidence may justify a later optimization proposal population. If a specific confounder needs intervention, that is a separately proposed, frozen, validated diagnostic—not an unreviewed checksum/warmup/score rewrite during this study. No specialization workaround or new target-code variant is authorized here.

Stop or mark diagnosis unresolved on failed correctness/scope, losses, nonmatching actual code, unsupported counter runtime, unexplained caller mapping or insufficient observations.
