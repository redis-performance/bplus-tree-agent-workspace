# Required performance guards

The exact cells, score layouts, operation counts and seed sets are frozen in [guard-manifest.json](guard-manifest.json) before the first candidate timing. Existing standard and member-length guards use the unchanged root referee. All eight operations and all five standard sizes remain required.

The equal-score, alternating signed-zero and mixed-finite construction/traversal performance referee does not yet exist. These guards are explicitly UNIMPLEMENTED/NOT RUN; correctness oracles do not satisfy them. If a primary contender survives, the missing referee must be separately validated, frozen and A/A qualified before its comparison. Missing or budget-truncated guards force PARK. No adoption overnight.

Each phase has its declared 300-second timing cap. No guard is removed to fit the budget or improve a result. Fresh confirmation uses seeds 101/102/103, six ABBA blocks, exact original primary counts and binary hashes, under independent root control after an explicit idle handover.
