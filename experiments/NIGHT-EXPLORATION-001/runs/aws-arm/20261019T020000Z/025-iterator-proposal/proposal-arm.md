## One falsifiable mechanism

Replay the exact retained EXP-005 A patch: inside the unchanged nonzero-width block,
replace the conditional width mask with UINT64_MAX>>(64-bits). No other source,
iterator state, public header, lookup/consumer, cross-word predicate, endian conversion,
score shift, physical reversal or ordered-double conversion changes. This can express
the full-width case without the baseline CMP/CSINV selection; Clang18 AArch64 may
produce a shorter native mask dependency sequence. It may instead emit equivalent or
slower code. That uncertainty is precisely what a native replication would resolve.

Before timing, compare isolated native control/A code for this function and relevant
shared decoder callers. If the mask does not lose at least one dynamic instruction
on the ordinary nonzero-width path, or introduces an additional conditional branch,
stop NONE without searching alternative source formulations. This is a feasibility
gate, not a prediction that static count proves speed. The exact patch is immutable;
do not swap in B/C or tune constants after data.

Prediction: exact semantics and owned memory remain unchanged; any gain should appear
in score-consuming paths, while no-output/length-only modes should have no direct
mask benefit. A>=2% dual-primary improvement is plausible but uncertain at this small

replication; no retries or changed duration/seed schedule. Any survivor still needs
independent fresh confirmation and every preregistered guard, not an average rescue.
