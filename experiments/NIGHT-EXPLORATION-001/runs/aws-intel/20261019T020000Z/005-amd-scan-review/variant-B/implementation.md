The native SSE2 path consumes complete pairs of existing8-byte words, loading16 bytes with memcpy into an intrinsic vector. Exact equality masks cover tag itself and, for tag1, physical zero as well. A nonzero16-bit movemask is enumerated with ctz and clear-lowest-bit. Ascending physical positions are mapped through the original reversed logical formula. After complete pairs, the unchanged original SWAR loop consumes an optional8-byte word and the original scalar loop consumes remaining bytes. This shares the original tail and keeps the portable implementation without a second helper or alternative algorithm.

The compile-time capability condition is `defined(__SSE2__) && !defined(ZBT_LEAF_TAG_MATCHES_FORCE_PORTABLE)`. The macro is for correctness-only fallback validation; normal timing flags must not define it. The emmintrin include uses the same guard. No global compiler flags, new exported API, state, memory allocation, hashing, index or callback behavior changes.

Bounds proof: words=floor(count/8); a vector iteration requires w+1<words and starts at8*w, so its last byte8*w+15 is at most8*words-1<count. w advances by2. An odd complete residual word starts at8*w with w<words; the scalar tail starts at8*words. No vector overlap, padding read or masked out-of-range lane is needed. ctz is called only when mask!=0, and movemask has only16 possible bits. Each matching physical byte contributes once. Tag1's equal-zero/equal-one lane sets are disjoint. Zero-count and count<16 inputs perform no vector read. Unsigned last=count-1 may wrap for zero count exactly as baseline, but no position is emitted.
