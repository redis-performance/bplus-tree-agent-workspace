Root and independent B review, final input freeze publication and an explicit published authorization ACK precede execution. The command is `python3 <023>/validate.py --ack <authorization-json>`, from repository root. No benchmark workload or timing comparison is executed.

The driver uses the exact four sources in `source-manifest.json`, prepared as isolated partial Git worktrees at corrected commit `13e459ff8800be3f02b6b45c87dd7b0c39453fa9`. The unchanged original NEON patches and designated portable macros retain their original authors. Native and sanitizer flags come verbatim from `PLAN.json`; relative source/include/build arguments and working-directory structure match across all four sources. Common compile inputs are `compat/standalone.c`, `vendor/redis/siphash.c` and `-lm`; the all-match/private oracles include the tree source themselves, so no second tree C file is linked. No architecture flags, assertion changes, alternate allocator or hash are introduced.

For base/A/B/C and native/sanitizer, retain the original 43-test Makefile check, unchanged V2 all-match oracle, scan interval, wide scan seeds 7/19, live widening seeds 7/19 and resize generation. Semantic oracle stdout must match baseline byte-for-byte within each build mode; all eight original test invocations must report 43 passed and zero failed. Each candidate additionally runs its designated forced-portable V2 in both modes, matching baseline. This preserves eight original-test runs, 56 positive oracle runs and six forced-portable runs, with their builds separately journaled.

Four isolated copies of A reproduce the exact original fault substitutions: omit folded-zero equality, reverse physical lane order, omit residual tags, and load a vector when one complete word remains. Each must fail the unchanged V2 under native and sanitizer, eight negatives. Negative-only `ASAN_OPTIONS=symbolize=0` retains memory checking and avoids symbolizer stalls. A recognized V2 assertion with SIGABRT, or a sanitizer diagnostic with its allowed status/signal, is required; unrelated crashes/loader failures/timeouts do not qualify. Record diagnostics and do not claim a guard-page signal unless the actual result supports it. Original candidate sources/builds remain untouched. Fault patches are retained.

Mac metadata replaces Linux-only affinity/objdump/objcopy actions. Capture actual Clang version, all predefined source macros and `otool -tvV` output. Candidate native activation requires AArch64/NEON definitions plus the source-local native guard. Candidate scan-slot code must contain vector registers, narrowing and vector comparison instructions. Missing proof stops eligibility rather than timing a fallback. Parse immutable Mach-O load commands to hash the native `__text` section and retain complete binary identities. Fresh A/A will use this newly frozen baseline binary; no Linux control binary or previously qualified M6 binary is substituted.

The ACK requires exclusive runner/all other work idle and binds exact driver, PLAN and freeze hashes, a published commit, root PASS and independent B PASS. Source/referee/patch inputs must match the final frozen digest table. Every native child runs serially, in its worktree, in a newly owned process group. Per-child time is at most 120 seconds and clipped to remaining phase/UTC budget with ten seconds reserved for cleanup. A parental real-time alarm bounds the phase at 600 seconds or 07:15 UTC, whichever comes first. Interruptions, spawn failures and timeouts preserve their journal and all existing raw output. Cleanup blocks SIGALRM/SIGTERM/SIGHUP/SIGINT delivery, sends owned-group TERM, waits one second, then KILL if needed, reaps within five seconds and observes group disappearance for three seconds. No unrelated process search or cleanup occurs.

Raw byte logs stay under ignored `scratch/m6-neon-validation`; public derivatives replace workspace and user-home prefixes with generic tokens and retain raw/public hashes. Existing output directories reject overwrite/retry. All source/input identities are rechecked after success and again in finalization, including failed phases. The watchdog remains active through final hashes; produced and fault binaries are inventoried even after failure. Final serialization is followed by another phase/UTC bound check, with any late PASS downgraded to failure. Successful validation freezes all produced native/sanitizer binaries before any comparison. Any failure, incomplete output, cleanup problem, deadline breach or identity mismatch stops progression. No repair or weakened check is authorized.
